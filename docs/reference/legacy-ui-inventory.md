## 1. 前作定位与核心循环

### 1.1 一句话定位

在虚构大陆「云澜」与世界版图上，玩家接手一家只有两座车站、一列东风4 型机车的铁路公司，靠**开站 → 开线 → 配车 → 日结**把路网从家乡支线铺到跨洲干线（19 地区 541 城 226 车）。

### 1.2 五步核心循环

| # | 步骤 | 玩家动作 | 页面 | 主要产出 |
|---|---|---|---|---|
| 1 | **开站** | 地图点城市开站（¥200/城） | 线路页 | 车站解锁、可建区间出现 |
| 2 | **开线** | 编排页选起终点 + 可选途经站 + 填编号 + 选车 → 确认 | 编排页 | 线路（首线免费免工期，之后付造价 + 2 营业日施工） |
| 3 | **配车** | 车队页按线路组加车 / 调度 / 改造 / 出售 | 车队页 | 线路运力（客/货）、日成本 |
| 4 | **经营** | 1×/2×/3× 时间流动，每日自动结算（可手动立即结算） | 全局顶栏 + 日结单 | 营收 − 支出 = 日净利；现金/累计净利/运营里程 |
| 5 | **扩张** | 用现金开新线、升级车站（6 级）、改造车辆（3 级）、买新车型、解锁新区域 | 线路/车队/机车页 | 接入城市数 ↑ → 网络协同加成 ↑ → 区域门槛达标 |

**支撑系统**（不占主循环但每天都碰）：日结单、离线收益、广告福利、编年史（23 章）、里程碑（33–34 条）、城市纪念章、每日签到、排行榜、每日挑战、铁路经理（自动经营）、云备份。

### 1.3 关键数值口径（B，源码可复核）

```
SafeAreaView
├── HUD 顶栏（header.lua，两行 + 当日进度条）
│   ├── 行1：[排行] [开始/暂停] [倍速 1×2×3× ▾ +剩余] [设置] …… [0%][进度条]
│   └── 行2：现金+ | 接入城市+ | 钻石+ | 运营日 D1
├── 通告条（header.ticker：纸签「通告」+ 单行截断 38 字，点击看全文）
└── 当前页（Tab 内容，切换不重建 HUD）
    ├── 线路： [大洲▾][‹][区域 chips 横滑][›] + 地图卡 + 网络协同面板
    ├── 编排： ScrollView（routeplanner：选站/途经/编号/多选车/预估/开线/已有线路）
    ├── 车队： ScrollView（缺口汇总 + 筛选 + 批量改造/一键整理 + 按线路分组的车辆行）

└── 底栏 5 页签（mapcard.tabs：线路 / 编排 / 车队 / 机车 / 日志）
```

## 8. 可继承 / 必须重做

### 8.1 新作方向要点（本次判断的前提）

竖屏 · **手绘城市地图** · **直接在图上画地铁/铁路线** · 以**城市为单位**经营 · **地标打卡** · **城市切换**（参考 TapTap《地铁线路模拟器》）。

## 9. 前作踩坑清单（25 条，均带证据路径）

### 9.1 引擎 / 渲染

1. **`children` 里的 nil 会截断后续控件**（引擎用 `ipairs` 遍历）→ 底栏缺项、未拥有机车无图、收集进度不显示。修法：构造适配层压实列表 + 拒绝把单个 Widget 当列表。证据：`docs/qa/UI_REPAIR_ACCEPTANCE_20261022.md` §1。
2. **纯 UI 项目 `scene_stalled=true` 是正常的**（没有 Scene 节点），不是失败。证据：`docs/PROJECT_BRIEF.md`。
3. **`-graphicsheadless` 下没有 UI 布局**——连 `boot-start` 节点都不存在，只能跑纯逻辑脚本；UI 测试必须开真实窗口（隐藏即可）。证据：`docs/design/performance-2026-11.md`。
4. **`--duration-ms` 太短会让进程在写 `validate.json` 前被杀**，表现成 `ENOENT validate.json`，会被误判为代码错误；截图帧要比总帧数早 ≥3 帧。证据：`docs/HANDOVER.md`。
5. **帧尖峰被当成失败**：headless 第 1322–1328 帧有 115–122ms 单帧抖动，无脚本报错（疑资源下载/GC），默认 100ms 阈值把它记成 engine error；项目改用 500ms 阈值。**要区分「失败 / 通过 / 未判定」**。证据：`HANDOVER.md` §四、`LESSONS.md` §8。
6. **1px 布局溢出警告**（`map-city-suzhou` 的标签 90 比容器 89 宽）——肉眼不可见，但会在日志里长期存在；不要靠关告警换通过。
7. **字体子集缺字**：默认中文字体缺失、人民币符号 `¥` 缺字形 → 必须自带可分发字体子集并做字形覆盖检查。证据：`UI_REPAIR_ACCEPTANCE` §6、`check_train_font_coverage.py`。

### 9.2 性能

8. **整树重建是最大卡顿点**：`RefreshUI` 平均 4.25ms / 首帧 10ms；解决了"整页重建"才轮到逻辑优化（Lua 日结只有 0.29ms）。证据：`docs/perf-and-save-compat.md`。
9. **541 城全量建 widget**：`Map.build` 40–55ms、首次进线页 78ms；改为视口惰性创建（单帧 ≤64 个）+ 缓存键后降到 1–2ms / 7ms。证据：`performance-2026-11.md`。
10. **存档落盘 3.5ms → 1.5ms**：不要每次保存都跑 5–7 遍 `fromSaveData` 迁移，改用轻量 rawKind 校验。证据：`perf-and-save-compat.md`。
11. **进度条宽度没变还写样式**、**现金动画超频**导致低端机掉帧；改为宽度不变跳过写入、动画限 30fps、只改单个 Label。证据：`AD_REWARDS_AND_LOW_END_20261027.md`。
12. **筛选/候选重复全量扫描**：203 个途经站候选从 17 次完整扫描排序降为 1 次。证据：同上。

### 9.3 数据 / 存档

13. **城市 ID 含下划线导致读档丢整条线**：`segmentById` 用 `^direct_([^_]+)_([^_]+)$` 解析，港澳台 `tw_taipei` 等 11 个节点解析失败 → 冷启动时整条直达线被静默丢弃。修法：逐下划线切分 + 两端校验。证据：`HANDOVER.md` 本轮状态。
14. **读取时静默夹取非法值 = 把数据损坏伪装成正常**：一次对负现金的区间夹取，实际效果是"重新读档即可免债"。**新作必须：缺失回退默认，非法隔离并报告。** 证据：`DECISIONS.md` D-H1、`player-review-20261022.md` P1-2。
15. **读档时对无效线路直接拒绝**（1.8.0 前）→ 改为"按城市端点自动重建失效线路、下线车型换起手车"，否则老玩家一升级就进不去。证据：1.8.0 trial_note、`e2b4be2 feat: repair old saves instead of rejecting them`。
16. **主档 + 备份同时损坏时静默开新局** → 必须明确提示并让玩家选择。证据：`player-review` P1-11。

### 9.4 交互 / 语义

17. **两页展示同一组对象与操作** → 玩家分不清该去哪；重切为「编排页=线路的家 / 车队页=车的家」，配车只在车队页，编排页只留导航提示。证据：`docs/design/page-roles.md`、`DECISIONS.md` D-E1。
18. **「跳过引导」被实现成「关闭指引」** → 一个布尔同时控制弹窗与目标条，跳过弹窗后用户永久失去下一步提示。修法：两个状态。证据：`DECISIONS.md` D-F1。
19. **关旧弹窗→开新弹窗→全量重建**在数帧内完成两次模态切换，用户看到白闪；改为面板内翻页 + 原地更新。证据：`LESSONS.md` §5。
20. **广告：累计 15 秒判超时**，正常长视频被先判失败、成功回调无法发奖；旧回调还会通过共享 `pending` 结束新请求。修法：每次请求独立身份、只收尾一次、长视频上限 180 秒、切换公司后旧回调失效、观看期间暂停经营时钟。**这是新作接广告时最容易复发的坑。** 证据：`AD_REWARDS_AND_LOW_END_20261027.md`。
21. **Mock 广告在正式包也发奖** → 发布前必须把 `isReal()==false` 的 Mock 成功改为失败。证据：`iaa-integration.md` §七。
22. **文案与账本口径不一致**：通告写 `¥-57` 而 HUD 写 `−¥57`；施工「2 个营业日」边界不清（当天已结算会以为第 3 天通车）；「区域联通」里程碑实际只要求开站。**所有面向玩家的数字走同一个格式化函数，规则要在文案里说清边界。** 证据：`player-review` P2-1/P2-4/P2-15。

### 9.5 设计与内容

23. **"191 城 / 541 城"分母造成开局压力**：顶栏写「接入城市 0/191」让新手觉得要铺 191 城；改为「0 座」，总数只放图鉴/成就。证据：`player-review` P2-9。
